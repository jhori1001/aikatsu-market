### パラレル版12枚を図鑑に追加し、通常版に入っていたパラレルの絵を直した

何を:
- `collectors/aikatsu.py`: 公式はパラレル版も通常版と同じ alt（例 "E1-01_PR"）で
  載せていて、違いは画像ファイル名・モーダルidの "_p1" だけだった（下見で実測）。
  alt を番号にしていたため2枚が1枚に潰れていたので、パラレル版は
  "E1-01_PR_p1" という別カード（`is_parallel=true`）として取り込むようにした。
  新しく作るときだけ、通常版の名前・アイドル名を写す。
- `jobs/crawl.py`: 保存済み画像の取得元URLがカードの画像URLと違えば取り直す。
  dry-run でDBと見比べた結果（新規・URLが変わる・画像の取得元が違う）を出す。
- フリマの相場（`track_prices.py`）は通常版だけ追う（パラレル版は対象外）。
  `fetch_shop_prices.py` は通常版のカードにだけ番号を対応づける（ショップの
  パラレル版の値段は、これまでどおり通常版の card_pk に is_parallel=true で持つ）。
- 画面: パラレル版のカードには「PR★」「ER★」の印と「パラレル」の札を付け、値段は
  フルアヘッドのパラレル版の価格（推移のグラフも）を出す。番号は "_p1" を外して見せる。
- 画像URLに版（`?v=` 保存した画像の sha256 から作る）を付けた。同じURLだとCDNが
  30日キャッシュしていて、差し替えた絵が出ないため。

なぜ: ユーザーの指摘「パラレルのカードないから確認して。公式サイトにあるからそれを追加して」。
調べると、取り込みのときに後から読んだパラレル版が通常版を上書きしていて、
通常版の12枚にパラレル版の絵が出ていた。

### 相場からパラレル版・別シリーズ・2枚組などを外し、日次平均を付け直した

何を: `jobs/track_prices.py` の判定（`exclusion_reason`）に
パラレル・旧シリーズ（スターズ・プラネット等、旧番号 01-19P 等）・別番号（SP-014 等）・
コーデ一式／2枚以上・他カード名入り・自分以外の部位名入りを追加。
同じ出品が別カードの検索でも見つかったとき、別カードの物差しで判定を
上書きしていた不具合も直した（同じカードの行だけ更新する）。
保存済みの出品へ当て直す `jobs/rejudge_listings.py` / `rejudge.yml`（dry-run付き）を追加。

なぜ: E1-04 の出品一覧に、パラレル版（16,000円・13,680円）やスターズ版、
SP-014 が通常版として混ざり、平均を押し上げていた（ユーザーの画面写真で発覚）。

DBにしたこと（rejudge、dry-run を3回見てから本番）:
- 採用→除外 394件、除外→採用 3件（3件とも1枚だけの正しい出品で、別カードの
  検索で判定が上書きされていたもの）。日次平均が変わった行 39。
- 例（10/30）: E1-04 8,720円(35件) → 3,830円(19件)、E1-30 4,960円(110件) → 1,480円(26件)、
  E1-02 6,830円(48件) → 3,830円(24件)。
- 1回目の dry-run では除外→採用が12件出たので1件ずつ見たところ、フルコーデ・
  2枚組・旧番号入りだったため、ルールを足して数え直した（12 → 4 → 3）。
