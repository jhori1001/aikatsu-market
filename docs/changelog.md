### 相場からパラレル版・別シリーズ・2枚組などを外し、日次平均を付け直した

何を: `jobs/track_prices.py` の判定（`exclusion_reason`）に
パラレル・旧シリーズ（スターズ・プラネット等、旧番号 01-19P 等）・別番号（SP-014 等）・
コーデ一式／2枚以上・他カード名入り・自分以外の部位名入りを追加。
同じ出品が別カードの検索でも見つかったとき、別カードの物差しで判定を
上書きしていた不具合も直した（同じカードの行だけ更新する）。
保存済みの出品へ当て直す `jobs/rejudge_listings.py` / `rejudge.yml`（dry-run付き）を追加。

なぜ: E1-04 の出品一覧に、パラレル版（16,000円・13,680円）やスターズ版、
SP-014 が通常版として混ざり、平均を押し上げていた（ユーザーの画面写真で発覚）。

DBにしたこと（rejudge、dry-run を3回見てから本番）:
- 採用→除外 394件、除外→採用 3件（3件とも1枚だけの正しい出品で、別カードの
  検索で判定が上書きされていたもの）。日次平均が変わった行 39。
- 例（10/30）: E1-04 8,720円(35件) → 3,830円(19件)、E1-30 4,960円(110件) → 1,480円(26件)、
  E1-02 6,830円(48件) → 3,830円(24件)。
- 1回目の dry-run では除外→採用が12件出たので1件ずつ見たところ、フルコーデ・
  2枚組・旧番号入りだったため、ルールを足して数え直した（12 → 4 → 3）。
